Social-pulse sources

  • Traffy Fondue — pin-level citizen complaints, public share API (publicapi.traffy.in.th), GPS joined directly to community polygons. Rolling ~100-report public sample.
  • News RSS — Thairath, Sanook, Prachatai feeds plus 158 Google News RSS queries (one per khwaeng, top-40 slums by population).
  • Pantip — public search threads parsed from the page payload.
  • Telegram — public channel web previews (t.me/s/); channels with 5,000+ verified followers, Thai-language exemption; subscriber counts cross-checked against independent crawlers.
  • Gazetteer — 5,120 Thai name variants over 626 BMA slum polygons, built from official names, landmarks, khwaeng/district names and famous area aliases.
  • Event lexicon — ten deprivation domains grounded in the Domains of Deprivation Framework, SDG 11.1.1 and the Slum Severity Index; Thai NLP via PyThaiNLP; machine translation via DeepSeek API.

Caveats

Household and resident figures on NHA community points are modeled (log-normal distribution calibrated to official NHA/CODI aggregates), not surveyed counts. Official community locations exist only in NHA/BMA registers — slums are not a zoning category in Thai comprehensive plans (ผังเมืองรวม). AI roof footprints and slum-group blobs are model output for triage, not legal delineation; terraced rows can merge into single polygons, and the spacing metric measures gaps between built blocks.

Traffy Fondue public endpoint exposes only a rolling ~100-report sample; Google News items remain snippet-only. No API keys are stored in the repository.
